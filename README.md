## 概述

一个试图将东方夜雀食堂在 MC 中还原的模组。

（虽然游戏内本地化的模组名称是夜雀食堂，但夜雀乐事听起来更好听（bushi））

目前的模组将游戏中本体及五个 DLC 内容的食材和酒水添加进了游戏，而所需的食材可以通过原版食材合成。

料理包括了夜雀食堂本体内容，且均可以由本模组的制作方块——“灶”上使用各种厨具进行制作。

在版本 0.0.3a 中添加了 JEI 支持，可以在 JEI 中查看配方；

在版本 0.0.4 中添加了和夜雀食堂一样的 Tag  系统；

在版本 0.0.6 中添加了对妖怪们的归家的食材的联动；

在版本 0.0.6b 中添加了和夜雀食堂一样的左下角点单系统；

在版本 0.1.0 中加入了点单功能，完成了配方的数据驱动。

在版本 1.21-0.1.1 中使用内置的immersiveui重写了UI，并实现了沉浸的世界内UI。

在版本 1.21.1-0.1.4 中添加了kubejs支持

在版本 1.21.1-0.1.5 中添加了REI支持

在版本 1.21.1-0.2.1 中添加了额外定价修改，可以使用`/mystiasizakaya price_addon open`打开编辑器

## 玩法

在灶上进行料理，按照配方任意放入食材即可。单次点击选中目标，再次点击开始料理。（>1.21-0.1.1）

新增的悬浮UI，除了从厨具的UI中取出（<1.21-0.1.1/1.20.1）还可以点击悬浮的图标可以直接拿到成品。（>=1.21-0.1.1）

## 开店流程

制作一个账本

<=1.21.1-0.1.5

在一面墙上摆上物品展示框

手中拿着账本，先右键一次展示框绑定展示框，再右键一次绑定展示框内容，上下摆放的两个展示框视为同一菜单。

\>=1.21.1-0.1.6

打开账本UI，点击背景，会翻到下一页，右侧两列是菜单，拿起物品点击菜单物品栏即可设置。

在地上摆放餐桌，使用账本右键绑定餐桌

按住shift，手中拿着账本右键打开UI，点击左上角的“开始/暂停营业”，若配置正确聊天框将出现绿色的“开业成功”字样。

等待一段时间后，虚空顾客将产生订单，显示在屏幕的左下角。（有非常流畅的动画）打开餐桌的UI放入目标料理/酒水即可完成订单。（<1.21-0.1.1/1.20.1）餐桌上方也会显示该桌的订单，手中拿着目标料理/酒水点击悬浮UI也可以完成订单。（>=1.21-0.1.1）

打开账单，可以看到来自餐桌的收入

## 电话购物


点击图标开始购物，单次点击购买一个，按住shift点击清空库存。

右下角为购物车，点击购物车上的图标返还物品，按住shift全部返还。

电话购物存在冷却时间，可以进行配置。
